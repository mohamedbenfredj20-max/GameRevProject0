# Game Reverse Engineering Pipeline (GameRevProject0)

بيئة عمل مؤتمتة ومخصصة للهندسة العكسية لألعاب الأندرويد، مصممة للعمل بسلاسة عبر بيئات الـ RDP المؤقتة مع مزامنة الملفات والأدوات تلقائياً.

## 📂 هيكل المشروع (Project Structure)
- `setup.py`: السكربت الرئيسي المسؤول عن تجهيز البيئة بالكامل.
- `workspace/input/`: مخصص لملفات الإدخال الخام (مثل ملف الـ APK وأصول الـ CDN - يتم استبعاده من الرفع عبر `.gitignore`).
- `workspace/output/`: مخصص لحفظ نتائج ومخرجات التحليل.
- `tools/`: المجلد الذي يتم تحميل وتثبيت أدوات التحليل فيه تلقائياً.

## 🚀 طريقة التشغيل في أي بيئة RDP جديدة
بمجرد فتح جلسة RDP جديدة، قم فقط بتشغيل الأمر التالي في ترمينال المشروع:

```bash
python setup.py
